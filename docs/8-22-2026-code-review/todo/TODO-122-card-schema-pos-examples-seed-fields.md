## Why
Cards are isolated words with an emoji: no part of speech (only 77 meanings embed noun/verb/adj in prose), no example sentence, no collocation. POS would drive the conjugation drill automatically (CONJ_BANK is 33 hand-entered words), filter Study ("verbs only"), and help the segmenter (TODO-115) expand inflections. Example sentences give context on the back and enable cloze cards. And a trap: the seed re-merge `Object.assign`s a hard-coded list of display fields (`reading, romaji, meaning, kind, emoji, pitch, lesson`) — `sec` is not refreshed and any new field added to SEED never reaches an existing deck unless that list is edited.

## Current behaviour (verified)
- SEED rows L17–861: `term, reading, romaji, meaning, kind, emoji, lesson, (sec), (pitch ×4)`; 38+ rows carry ad-hoc extras (`past`, `particle`, `time`, `irregular`, `watch`, `politer` — 06 F-21).
- Seed merge L1331–1342: `byTerm` (L1334) and `Object.assign(ex, { reading: s.reading, romaji: s.romaji, meaning: s.meaning, kind: s.kind, emoji: s.emoji, pitch: s.pitch, lesson: s.lesson })` (L1337).
- `SCRIPT_SEED` L2947–3350: 34 scripts / 227 lines, each `{speaker, tokens:[{t, r?}], romaji, en}`; `lineText(tokens)` L3450.
- Card back L1993–2023 shows emoji/meaning/romaji/timetag/mnemonic/hook; no sentence.

## Intended behaviour
- Schema additions (all optional, backward-compatible): `pos` ∈ `n | v-ichidan | v-godan | v-irregular | i-adj | na-adj | adv | expr | particle | counter | pron | conj`; `ex: [{ ja, tokens?, en, src? }]` (0–2 examples; `src` = `"script:2-1"` or `"ai"`).
- `SEED_FIELDS = ["reading","romaji","meaning","kind","emoji","pitch","lesson","sec","pos","ex"]` drives the seed refresh: `SEED_FIELDS.forEach((f) => { if (s[f] !== undefined) ex[f] = s[f]; })` — a new SEED field reaches existing decks on the next `SEED_VERSION` bump. Never overwrite user-owned fields (`mn`, `susp`, stats).
- Examples v1 come from SCRIPT_SEED at build/seed time (no LLM): for each card, the first ≤ 2 script lines whose text contains the term (or reading) → `ex: [{ja: lineText(tokens), tokens, en, src: "script:"+name}]`. Generated by a script `tools/gen-examples.mjs` that writes `data/examples.json` (term|lesson|sec → ex[]) and is merged into SEED rows at build time, or simply pasted into SEED once. Prefer the build-time merge (keeps SEED readable).
- `pos` v1: hand-tag via a one-off script that proposes POS from heuristics (ends in る/う-row + meaning starts with "to " → verb; ends in い + meaning adjectival → i-adj; meaning contains "(な)" → na-adj; `〜` → expr/particle/counter) into `data/pos.json` for review; an LLM batch via TODO-125 can propose, a human reviews.
- Card back: after the meaning, show the first example `ja` (with `Furigana` when tokens exist, L2344–2352) and `en` in a `tc-exline` (small); a SpeakBtn for the sentence (TTS cache covers it).
- ConjDrill: `CONJ_BANK` stays; later, cards with `pos` starting `v-` can be offered ("Drill all deck verbs") — out of scope here, note only.

## Data migration / compatibility
Existing decks receive `pos`/`ex` on the next `SEED_VERSION` bump via the data-driven refresh. `mergeDeck` (L937–953) merges whole card records — a device that has not yet run the new seed loses nothing (fields arrive when it runs the bump). Snapshot size grows (≈ 821 × ~150 B ≈ 120 KB) — note for Theme A's payload-size item; keep `ex` to ≤ 2 short entries.
