# TODO-215 — Service worker: offline app shell, versioned by the build stamp, with an "update available" pill

**Priority:** P2   **Effort:** M   **Theme:** C — presentation/platform/maintainability
**Source findings:** 03-presentation-ui-ux-review.md § 6 Caching, § 9 PWA-ness; 05-expansion § 5.1 PWA/offline; 06-architecture § 3.1 (assets served by Worker)
**Depends on:** TODO-210 (build stamp), TODO-214 (manifest/icons)   **Blocks:** none

## Why
The app is a phone-first daily study tool, yet a cold open on the bus re-downloads a 549 KB HTML (226 KB compressed) with `cache-control: public, max-age=0, must-revalidate`, and with no network the student sees a blank indigo page. Study itself already works offline (localStorage + pending-sync flag); only the *shell* is missing. Because the whole app is one file plus `videos.json`, the precache list is tiny. The classic failure mode is stale HTML — versioning the cache by the build stamp and showing an "update available" pill handles it.

## Current behaviour (verified)
- Live headers: `cache-control: public, max-age=0, must-revalidate`, `cf-cache-status: HIT` (report 03 § 6); no SW registration anywhere (`grep -c serviceWorker JpnFlashcards.jsx` → 0; `index.html` head L1-12 has none).
- Assets: `cf/public/index.html`, `cf/public/videos.json` (built), Worker SPA fallback for any other path (`cf/wrangler.toml`).
- TTS responses are `cache-control: public, max-age=31536000, immutable` (`cf/src/index.js:163`) and fetched by URL (`TTS_ENDPOINT + "?text=…"`, L3385, L3397) — already long-cached by the HTTP cache; `prefetchJa` uses `cache:"force-cache"`.
- `/videos.json` is fetched with `cache:"no-cache"` and cached in localStorage (`loadVideoIndex`, L4196-4215).
- API routes: `/api/sync`, `/api/tts`, `/api/feed` and the `/.netlify/functions/*` aliases (Worker L362-367).

## Intended behaviour
`/sw.js` (served as a real asset from `cf/public/`, generated by the build with the stamp baked in) precaches `/`, `/manifest.webmanifest`, the icons, and `/videos.json`; serves `/` cache-first (so a cold open is instant and works offline), `/videos.json` stale-while-revalidate, `/api/tts?*` cache-first (immutable), and everything under `/api/*` (and `/.netlify/functions/*`) **network-only** (never cache sync). On activation of a new SW version the page shows a small "Update available — Reload" pill. Scope `/`.

## Implementation steps
1. **`public/sw.js`** (template; the build replaces `__BUILD__`):
   ```js
   const VERSION = "__BUILD__";
   const SHELL = `tangocho-shell-${VERSION}`;
   const TTS = "tangocho-tts-v1";
   const PRECACHE = ["/", "/manifest.webmanifest", "/icons/icon-192.png", "/icons/icon-512.png", "/videos.json"];
   self.addEventListener("install", (e) => { e.waitUntil(caches.open(SHELL).then((c) => c.addAll(PRECACHE)).then(() => self.skipWaiting())); });
   self.addEventListener("activate", (e) => {
     e.waitUntil((async () => {
       for (const k of await caches.keys()) if (k.startsWith("tangocho-shell-") && k !== SHELL) await caches.delete(k);
       await self.clients.claim();
       for (const c of await self.clients.matchAll({ type: "window" })) c.postMessage({ type: "sw-activated", version: VERSION });
     })());
   });
   self.addEventListener("fetch", (e) => {
     const url = new URL(e.request.url);
     if (url.origin !== location.origin || e.request.method !== "GET") return;
     const p = url.pathname;
     if (p.startsWith("/api/sync") || p.startsWith("/.netlify/functions/sync") || p.startsWith("/api/feed") || p.startsWith("/.netlify/functions/feed")) return; // network only
     if (p.startsWith("/api/tts") || p.startsWith("/.netlify/functions/tts")) {          // immutable audio: cache-first, but never cache 401s
       e.respondWith((async () => { const c = await caches.open(TTS); const hit = await c.match(e.request); if (hit) return hit;
         const res = await fetch(e.request); if (res.ok && res.headers.get("content-type")?.startsWith("audio/")) c.put(e.request, res.clone()); return res; })());
       return;
     }
     if (p === "/videos.json") {                                                            // stale-while-revalidate
       e.respondWith((async () => { const c = await caches.open(SHELL); const hit = await c.match(e.request);
         const net = fetch(e.request).then((res) => { if (res.ok) c.put(e.request, res.clone()); return res; }).catch(() => hit);
         return hit || net; })());
       return;
     }
     if (p === "/" || p === "/index.html" || e.request.mode === "navigate") {              // app shell: cache-first
       e.respondWith(caches.match("/").then((hit) => hit || fetch(e.request)));
       return;
     }
     e.respondWith(caches.match(e.request).then((hit) => hit || fetch(e.request)));       // icons/manifest
   });
   ```
2. **Build**: in `tools/build.mjs` after copying `public/` → `cf/public/` (TODO-214 step 4), read `public/sw.js`, replace `__BUILD__` with `BUILD` (TODO-210), write `cf/public/sw.js`. Never copy the un-substituted template.
3. **Register + update pill** — in `main.jsx` (TODO-212) after mount:
   ```js
   if ("serviceWorker" in navigator && location.protocol === "https:") {
     navigator.serviceWorker.register("/sw.js").then((reg) => {
       reg.addEventListener("updatefound", () => { const nw = reg.installing; nw?.addEventListener("statechange", () => { if (nw.state === "installed" && navigator.serviceWorker.controller) flash("Update available — reload to get it", { kind: "info", ms: 8000, action: { label: "Reload", run: () => location.reload() } }); }); });
     }).catch(() => {});
   }
   ```
   Extend the toast from TODO-207 to accept an optional `action` button. (If TODO-207 is not in yet, render a `.tc-updatepill` in the header instead.) Also `navigator.serviceWorker.addEventListener("controllerchange", () => …)` is not needed because `skipWaiting` + `clients.claim` make the *next* load use the new shell; the pill just makes it sooner.
4. **Worker headers**: serve `/sw.js` with `cache-control: no-cache` (so the browser revalidates the SW script promptly) — either add a `cf/public/_headers`-style rule (Workers assets support `_headers` files: `/sw.js\n  Cache-Control: no-cache`) or special-case in `cf/src/index.js` before `env.ASSETS.fetch`. Keep `/` at `max-age=0, must-revalidate` (default).
5. **Dev guard**: only register on `https:` (prod) so `python3 -m http.server` and `wrangler dev` on http don't get a sticky SW; `localhost` is allowed by browsers but skip it to keep dev simple.
6. Rebuild; commit `public/sw.js`, `tools/build.mjs`, `main.jsx`, `index.html`.

## Data migration / compatibility
Cache names carry the build stamp; old shells are deleted on activate. The TTS cache is versioned separately (`tangocho-tts-v1`) and survives app updates. To force a reset in the future: bump the `TTS` name.

## Testing & verification
- Prod after deploy (SW needs https): DevTools → Application → Service Workers shows `sw.js` activated; Cache Storage has `tangocho-shell-<build>` with 5 entries.
- Toggle "Offline" in DevTools → reload → the app loads from cache; Study works; Browse sync box shows "Not saved yet"; Input still lists indexed videos (cached `videos.json`).
- Deploy a new build → reopen → "Update available" pill within a few seconds; reload → `document.querySelector('meta[name=build]').content` is the new stamp; old cache name gone.
- `curl -sI https://tangocho.deskbuddies.workers.dev/sw.js` → `cache-control: no-cache`, `content-type: application/javascript` (or `text/javascript`).
- Sync still works offline→online (SW does not touch `/api/sync`).

## Pitfalls / notes
- A cache-first `/` means a deploy is not visible until the SW updates — that is the trade; the pill + `skipWaiting` keeps it under a minute for open tabs and immediate on next launch.
- Never precache `/api/*`; never `caches.put` a 401/`text/html` TTS response (the `content-type` check above).
- If `not_found_handling` is changed to `404-page` (TODO-214 step 6), `navigate` requests to unknown paths will 404 — fine, the app has only `/`.
- Rebuild + commit `index.html`; `cd cf && npx wrangler deploy`.
