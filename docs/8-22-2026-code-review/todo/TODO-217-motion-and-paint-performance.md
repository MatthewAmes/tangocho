## Why
`prefers-reduced-motion` is honoured for CSS (transitions/animations are killed) but the mascot is an animated **GIF**, which CSS cannot pause — a vestibular-sensitive student gets a perpetually wiggling sprite on the home screen. Separately, 49 section chips each composite a `backdrop-filter: blur(9px)` layer plus a full-viewport `position:fixed` noise layer with `mix-blend-mode:soft-light`; scrolling the home screen at 375px painted off-screen chips as blank slabs for a frame (observed), and mid-range Android will drop frames. Browse renders 821 rows (~4–5k nodes) with no containment.

## Current behaviour (verified)
- Mascot: `Mascot()` L1250-1254 renders `<img className={"tc-mascot is-"+state} src={MASCOT_GIFS[state] || MASCOT_GIFS.waiting} …>`; `data/mascot.js` exports animated GIF data URIs (one per mood) generated by `tools/make-mascot.mjs` (frames drawn from shapes; `encodeGif` from `tools/gifenc.mjs`).
- Reduced motion CSS: L5814-5816 `.tc-card-inner{transition:none}`, L6027 `.tc-combo{animation:none}`, L6079 `.tc-root *{transition:none !important;animation:none !important;}`.
- Chips: `.tc-batchglass` L5685 `backdrop-filter:blur(9px) saturate(150%);-webkit-backdrop-filter:…`; 49 chips rendered L1886-1902.
- Noise: `.tc-root::after` L6076-6077 `position:fixed;inset:0;…opacity:.05;mix-blend-mode:soft-light;background-image:url("data:image/svg+xml,…feTurbulence…")`.
- Other blur users: `.tc-tabs` L5640 (20px), `.tc-face` L5729 (22px, both faces during the flip), `.tc-card2` L5940 (22px).
- Browse rows: `.tc-prow` L5909; list rendered L4036-4062 (all `shown`, no pagination).

## Intended behaviour
- Under `prefers-reduced-motion: reduce` the mascot is a **static first-frame** PNG/GIF (same art), not animated.
- Chips keep the glass *look* (gradient + 1px border + inset highlight) without `backdrop-filter`; the noise overlay and chip blur are enabled only on wide screens (`min-width:700px`) where the GPU budget allows; the card faces keep their blur (1–2 layers).
- Browse rows use `content-visibility:auto` with an intrinsic size so off-screen rows cost nothing to lay out.

## Implementation steps
1. **Static mascot frames.** In `tools/make-mascot.mjs` also emit a *single-frame* GIF per mood (call `encodeGif` with `[frames[0]]` or the frame list of length 1 — check `gifenc.mjs`'s signature; NETSCAPE loop extension is irrelevant for one frame) into the same `data/mascot.js` as `export const MASCOT_STILLS = { sleeping: "data:image/gif;base64,…", … }`. Regenerate with `node tools/make-mascot.mjs` (it writes `data/mascot.js`; the header says "GENERATED — do not edit by hand").
2. **Pick still vs animated** in `Mascot()` (L1250):
   ```jsx
   import { MASCOT_GIFS, MASCOT_STILLS } from "./data/mascot.js";
   const reduceMotion = () => typeof matchMedia === "function" && matchMedia("(prefers-reduced-motion: reduce)").matches;
   function Mascot({ state, size = 84 }) {
     const [still, setStill] = useState(reduceMotion);
     useEffect(() => { const mq = matchMedia("(prefers-reduced-motion: reduce)"); const fn = (e) => setStill(e.matches); mq.addEventListener?.("change", fn); return () => mq.removeEventListener?.("change", fn); }, []);
     const set = still ? MASCOT_STILLS : MASCOT_GIFS;
     const src = set[state] || set.waiting || MASCOT_GIFS.waiting;
     return <img className={"tc-mascot is-" + state} src={src} width={size} height={size * 30 / 32} alt={"Study buddy, looking " + state} draggable="false" />;
   }
   ```
3. **Chip blur + noise gating.** Replace the two `backdrop-filter` lines in `.tc-batchglass` (L5685) and the whole `.tc-root::after` rule (L6076-6077) with:
   ```css
   @media (min-width:700px){
     .tc-batchglass{backdrop-filter:blur(9px) saturate(150%);-webkit-backdrop-filter:blur(9px) saturate(150%);}
     .tc-root::after{content:"";position:fixed;inset:0;pointer-events:none;z-index:99;opacity:.05;mix-blend-mode:soft-light;background-image:url("data:image/svg+xml,…same…");}
   }
   ```
   and bump the chip's own background so it still reads as glass without blur: `.tc-batchglass{background:linear-gradient(155deg, rgba(255,255,255,.18) 0%, rgba(255,255,255,.07) 55%, rgba(255,255,255,.03) 100%);}` (was .16/.05/.02).
4. **Browse containment.** `.tc-prow{content-visibility:auto;contain-intrinsic-size:auto 96px;}` (L5909). Optionally cap the initial render: `shown.slice(0, visibleCount)` with a "Show more (721)" button (`visibleCount` state starting at 100, +200 per tap) — cheap and avoids 4k nodes when searching.
5. Rebuild.
