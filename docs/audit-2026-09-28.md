## Plan — phases and acceptance criteria

1. **Honest measurement** — *done this pass.*
   Accept when one success never masters a word, hinted or chosen answers cap FSRS
   credit, and the dashboard shows mastered / can recall / recognise only / not started
   against the whole volume. (`tools/proven.mjs`, `tools/test-proven.mjs`, the
   Plan tab's "Volume 2 — what you've proven", Study home stat.)
2. **Volume 2 vocabulary validated against the book.** Parse Appendix B properly
   (act, scene, page, part of speech), show a review screen for the 11 notation mismatches
   and ~40 missing words, and import only what Matthew approves. Accept when every Vol 2
   deck word carries book provenance or an explicit "supplemental" tag.
3. **Textbook kanji.** *Done 2026-09-29:* all 133 extracted with their scenes (`tools/extract-book-kanji.mjs` -> `src/data/book-kanji.js`, number/character/scene only, both PDF copies agree), the Kanji tab and Smart Review unlock in book order, and each kanji is shown by the best deck word it has been produced in (`tools/bookkanji.mjs`). 百, 昨 and 漢 appear in no deck word yet. Original plan: Extract the 133 numbered kanji with the scene that introduces
   each one, the readings taught at that point, and the example words. Queue the 37
   unclear numbers for review. Link each kanji to the deck words that use it. Order the
   Kanji tab by book number. Accept when a kanji's mastery is computed from its words, not
   its English keyword.
4. **Grammar inventory.** Record the ~101 BTS notes as grammar targets with scene
   provenance. Build exercises only where the answer is deterministic (conjugation, particle
   choice from textbook sentences). Flag the rest as "needs authored items" rather than
   generating them.
5. **Volume 2 as the active curriculum.** Cumulative act checkpoints built on the
   existing checkpoint engine, and the path advances an act only on demonstrated mastery.
6. **10,000-word layer.** `freq.json` exists. Label it supplemental everywhere, keep it
   out of the path until Vol 2 foundations hold, and deduplicate against the deck.
